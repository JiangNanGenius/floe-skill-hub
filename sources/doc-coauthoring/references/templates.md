# Co-authoring Templates

## context.md skeleton

```
# Purpose
- Decision/action wanted:
- Success looks like (for the reader):

# Audience
- Who:            Role:           Known already:
- Distrusts / objections:

# Facts & constraints (each with source)
- [fact] — source: workspace file / fetched URL / user statement / UNVERIFIED

# Voice reference
- sample 1 (quote 3-6 lines):
- register notes:

# Anti-goals
- must not become:
```

## Section self-check (run after every drafted section)

| # | Question | Pass rule |
|---|----------|-----------|
| 1 | Outcome sentence delivered? | one concrete takeaway, no "it depends" without a decision |
| 2 | Every claim traced? | source in context.md or explicit UNVERIFIED flag |
| 3 | Cuttable sentence? | if removing a sentence loses nothing, remove it |
| 4 | Jargon audit | terms defined on first use or already defined for this audience |
| 5 | Number/name/date drift | copy-paste from source, never retype |

## Reader-test protocol

1. Fresh read: skim headings + first sentences only. Write the argument you can reconstruct in ≤5 bullets. Compare against the intended argument. Mismatch = restructure, don't rewrite prose.
2. Objection list: three strongest skeptical objections → which section answers each → answer strength (direct/partial/none).
3. Independent pass (optional, when the task can delegate): reviewer subtask receives ONLY the finished document plus this protocol; the drafting conversation stays out of its context.

## Completion checklist (before delivery)

- [ ] outline-approved structure intact (no orphan sections added without a nod)
- [ ] draft-log.md summarizes each pass
- [ ] open questions listed explicitly (never silently dropped)
- [ ] exported format re-opened and verified
- [ ] final file named per user convention (v1, v2, final)
