- Trigger (real guest audit R3): the resolved Debian 13 riscv64 guest ran `python3 scripts/stats_verify.py --require-layer` and passed 9/9 checks, but only because the union install had already provisioned `python3-matplotlib` for the scientific-visualization skill. Treating that refusal as a green verifier would have been wrong, and the previous prose ("matplotlib is NOT part of this skill's declared pins", "optional uninstalled verifier") contradicted the verifier's real behavior.
